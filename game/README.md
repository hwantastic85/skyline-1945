# SKYLINE 1945 — 1주차 프로토타입

PRD의 **F-01(이동·사격·폭탄)**과 리스크 대응 항목인 **적탄 1,000발 벤치마크**를 담았다. 설치할 것 없이 `index.html` 파일 하나로 돌아간다. 그림은 모두 코드로 그려서 외부 에셋이 없다.

## 실행

`index.html`을 브라우저(Chrome, Safari 등)로 열면 바로 시작된다.

## 조작

| 동작 | 키보드 | 패드 |
| --- | --- | --- |
| 이동 | 방향키 / WASD | 왼쪽 스틱, 십자키 |
| 사격(누르고 있으면 연사) | Z / J | A |
| 폭탄 | X / K | B |
| 저속 이동 + 히트박스 표시 | Shift | RB |
| 벤치마크 켜기/끄기 | B / F2 | — |
| 재시작 | R | Start |

차지 샷은 F-03 범위라 아직 없다.

## 구조 (index.html 안)

- **고정 타임스텝:** 로직은 60Hz로 고정하고, 화면 주사율과 상관없이 같은 속도로 돈다. 처리 순서도 고정했다(입력·플레이어 → 아군탄 → 적 → 적탄 → 판정). 난수 시드를 고정해서 같은 입력이면 같은 결과가 나온다(리플레이 F-12 대비).
- **탄 풀:** 적탄은 객체가 아니라 고정 크기 배열(`Float32Array`, 최대 2,048발)로 관리한다. 그릴 때는 색 한 겹마다 경로 하나로 모아 그려서, 1,000발이어도 그리기 호출이 6번이다.
- **판정:** 적탄 판정 반지름은 보이는 크기보다 작게 잡았다(원형탄 2.5px, 쌀알탄 2px, 기체 히트박스 2px).
- **훈련 표적기:** 핑크 고리탄 18발과, 플레이어를 노리는 보라 쌀알탄 5갈래 부채를 쏜다.
- 개발용으로 브라우저 콘솔에서 `game.state`, `game.perf`를 들여다볼 수 있다.

## 1주차 확인 결과 (2026-11-27, Claude 앱 내장 브라우저)

| 항목 | 결과 |
| --- | --- |
| 이동 | 0.5초에 90px(3px/프레임) 이동 |
| 저속 이동 | Shift를 누르면 속도가 절반이 되고 히트박스 점이 보임 |
| 연사·명중 | 1.5초 연사로 표적기 HP 19 감소, 점수 증가 |
| 폭탄 | 3개에서 2개로 감소, 화면 탄 제거, 무적 적용 |
| 피격 | 잔기 2에서 1로 감소, 무적 120프레임, 하단에서 리스폰, 잔기가 바닥나면 GAME OVER |
| 적탄 1,000발 | 로직 평균 0.05ms(최대 1.4ms), 그리기 평균 0.47ms. 한 프레임 예산 16.6ms의 약 3% |

내장 브라우저 창이 백그라운드여서 화면 갱신이 초당 약 35회로 제한됐다. 그래서 FPS 숫자는 이 환경에서는 의미가 없다. 일반 브라우저에서 열어 오른쪽 위 FPS가 60을 유지하는지 직접 확인해야 한다.
